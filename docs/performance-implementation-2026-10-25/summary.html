What changed

Visible library rows, indexed lookups, background saves and player controls, bounded poster work, quieter idle updates, isolated PiP video updates, and safer download resume and shutdown.

Cards now include Remove and Delete. Delete confirms a move to Trash. Background monitoring removes files deleted from disk; uncertain offline entries display Unavailable. Partial torrent siblings stay blocked unless a live transfer verifies them.

Ubuntu VM, Xvfb/Openbox, software graphics and null audio. Pixel detection measures UI response, not physical display scanout. CPU contention was uncontrolled. This is a specific Back-path result; a whole-app 10× improvement and native video-render throughput are unproven. Native Windows/macOS behavior remains untested in this pass. Uncertain download ownership, including unavailable Windows drives or network filesystem errors, can still block local opens until resolved. Error transfers may need external free space or deletion before recovery; a long recheck can report a timeout while continuing. Saved torrent metadata over 16 MiB can block transfer startup after restart; Retry does not repair it.
